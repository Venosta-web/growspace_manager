# Grow Run history captures domain events and selected media

A Grow Run durably captures its cultivation configuration timeline, Growspace Manager activity events, participant identity snapshots, and only the images a grower explicitly attaches as Run Media. Arbitrary Home Assistant state changes remain in Recorder, raw telemetry is represented by metric summaries, and ordinary camera history is not copied. Capturing only final configuration or querying current source objects was rejected because later edits and deletions would erase the explanation for a Run's outcomes; copying all HA states and camera media was rejected because it would turn the Run store into an unbounded duplicate of Recorder and media storage. The accepted boundary preserves the causal cultivation record while keeping high-volume telemetry and incidental media out.
