# Grow Runs own durable historical summaries

An active Grow Run captures the durable facts and daily summaries needed for its historical report as activity occurs, and finalization freezes versioned comparison metrics derived from those records. Home Assistant Recorder remains a chart source but is not authoritative for a Grow Run: user-controlled Recorder retention, rolling water and alert limits, and missing archival energy baselines make later reconstruction incomplete and unstable. Recomputing every historical result from live Plants or retained Recorder states was rejected; the accepted trade-off is duplicated summaries and explicit metric-version evolution in exchange for history that survives retention, restart, and source deletion. Frozen values with different metric-definition versions are not compared; recalculation from retained facts requires an explicit audited re-finalization rather than a silent rewrite.
