# Finalized Grow Runs survive source deletion

Grow Runs transition from active, to completed while linked post-harvest outcomes may still arrive, to finalized when their comparison facts freeze. A finalized Grow Run retains the names and outcome facts needed to remain self-contained and readable even if its Growspace or participating Plants are later removed; source identities remain only as optional traceability links. Recomputing finalized history from live Plants, rolling Home Assistant Recorder data, or a still-present Growspace was rejected because today's destructive deletion and bounded telemetry retention would silently rewrite or erase comparisons. The accepted cost is duplicated historical facts and an explicit finalization boundary in exchange for stable, trustworthy run history. Growspace deletion is blocked while a Run is Active and requires Completed Runs to be finalized or voided; source deletion never cascades into Run history. Erasure remains possible only through a separate administrator-authorized Purge Run History action.
