# Versioned recipes with explicit zone overrides

Irrigation intent is captured in immutable, versioned Irrigation Recipes selected for physically compatible Irrigation Cohorts. Zone-specific tuning is stored as an explicit override rather than mutating the shared recipe, and lifecycle-stage transitions propose a visible version change instead of silently restamping defaults. This adds version and override management, but gives hobby growers stable presets while facilities gain approval, comparison, deployment, and rollback of exact agronomic intent.
